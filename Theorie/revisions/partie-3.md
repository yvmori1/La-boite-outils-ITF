# Révision — Partie III : La grammaire des techniques

3 questions tirées des [examens théoriques](../examens/README.md), avec leur corrigé. Répondez de tête, ouvrez le corrigé, puis notez-vous : le mode révision garde le score dans ce navigateur.

### Q1. Traduisez les termes de base suivants en coréen :

*Examen du 10e Gup, question 4 ([voir l'examen](../examens/ceintures-de-couleur/01-10e-gup.md)).*

* a) Attention !
* b) Salle d'entraînement (Dojang)
* c) Position de marche
* d) Position assise

<details markdown="1">
<summary><b>Afficher le corrigé</b></summary>

* **Réponse :**
    * a) Attention ! = **Charyot**
    * b) Salle d'entraînement = **Dojang**
    * c) Position de marche = **Gunnun Sogi**
    * d) Position assise = **Annun Sogi**

</details>

### Q2. Traduisez ces techniques de base en coréen ou en français :

*Examen du 9e Gup, question 5 ([voir l'examen](../examens/ceintures-de-couleur/02-9e-gup.md)).*

* a) Position en L
* b) Coup de pied circulaire (Dollyo chagi)
* c) Coup de pied de côté (Yop chagi)
* d) Blocage de l'avant-bras interne

<details markdown="1">
<summary><b>Afficher le corrigé</b></summary>

* **Réponse :**
    * a) Position en L = **Niunja Sogi**
    * b) Coup de pied circulaire = **Dollyo Chagi**
    * c) Coup de pied de côté = **Yop Chagi** ou **Yopcha Jirugi**
    * d) Blocage de l'avant-bras interne = **An Palmok Makgi**

</details>

### Q3. Associez ces termes techniques de l'examen à leur traduction :

*Examen du 8e Gup, question 5 ([voir l'examen](../examens/ceintures-de-couleur/03-8e-gup.md)).*

* 1. Position pieds joints
* 2. Coup de pied crocheté inversé
* 3. Blocage double de l'avant-bras
* 4. Coup de poing haut

<details markdown="1">
<summary><b>Afficher le corrigé</b></summary>

* **Réponse :**
    1. Position pieds joints = **Moa Sogi**
    2. Coup de pied crocheté inversé = **Bandae Dollyo Goro Chagi**
    3. Blocage double de l'avant-bras = **Sang Palmok Makgi** ou **Twin Forearm Block**
    4. Coup de poing haut = **Nopunde Jirugi**

</details>
