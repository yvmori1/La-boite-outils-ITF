# Les déplacements (Dolgi)

Voir le [chapitre 17 du manuel](../manuel/partie-5-repertoire-technique/17-les-deplacements-dolgi.md).

| Terme | Hangul | Traduction | Définition |
| :--- | :--- | :--- | :--- |
| **Dolgi** | [돌기](../../audio/termes/dolgi.m4a) | Rotation, pivot | Changement d'orientation du corps ; désigne aussi l'ensemble des déplacements. |
| **Didimyo** | [디디며](../../audio/termes/didimyeo.m4a) | En posant le pied | Déplacement d'un pas. |
| **Omgyo Didimyo** | [옮겨 디디며](../../audio/termes/omgyeo-didimyeo.m4a) | En déplaçant le pied | Déplacement d'un pied vers une nouvelle place. |
| **Nagagi** | [나가기](../../audio/termes/nagagi.m4a) | Avancer | Didimyo Nagagi, un pas vers l'avant. |
| **Duruogi** | [들어오기](../../audio/termes/deuleoogi.m4a) | Reculer | Didimyo Duruogi, un pas vers l'arrière. |
| **Ibo** | [이보](../../audio/termes/ibo.m4a) | Deux pas | Ibo Omgyo Didimyo, double pas. |
| **Gujari** | [그 자리](../../audio/termes/geu-jari.m4a) | Sur place | Gujari Dolgi, pivot sans changer de place. |
| **Mikulgi** | [미끌기](../../audio/grammaire/Mikulgi.m4a) | Glissement | Pas glissé qui ferme la distance. |
| **Jajunbal** | [잦은발](../../audio/termes/jateunbal.m4a) | Pas rapide | Changement de pied rapide pour ajuster la distance. |
| **Apuro** | [앞으로](../../audio/termes/apeuro.m4a) | Vers l'avant | Direction du déplacement. |
| **Dwiro** | [뒤로](../../audio/termes/dwiro.m4a) | Vers l'arrière | Direction du déplacement. |
