# YUL-GOK

> **Grade :** 5e Gup — Ceinture verte barre bleue

* **Nombre de mouvements :**  38
* **Diagramme au sol :**  (Hanja pour l'Érudit / Lettré)

| Diagramme | Description |
| ------ | ------ |
| ![**士**](../images/yul-gok.png) | YUL-GOK est le pseudonyme du grand philosophe et érudit Yi I (1536-1584), surnommé le 'Confucius de la Corée'. Les 38 mouvements de ce Tul se rapportent à son lieu de naissance situé sur le 38e degré de latitude, et le diagramme représente l'érudit (lettré). |

## Liste Détaillée des Mouvements

### Posture de départ : Position parallèle de préparation (Parallel Ready Stance / Narani Junbi Sogi).

1. Déplacer le pied gauche vers B pour former une position assise vers D tout en étendant le poing gauche horizontalement vers D (Annun So Soopyong Jirugi).
2. Exécuter un coup de poing moyen vers D avec le poing droit tout en maintenant la position assise vers D (Annun So Orun Joomuk Kaunde Ap Jirugi).
3. Exécuter un coup de poing moyen vers D with le poing gauche tout en maintenant la position assise vers D (Annun So Wen Joomuk Kaunde Ap Jirugi).
4. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers A pour former une position assise vers D tout en étendant le poing droit horizontalement vers D (Annun So Soopyong Jirugi).
5. Exécuter un coup de poing moyen vers D avec le poing gauche tout en maintenant la position assise (Annun So Wen Joomuk Kaunde Ap Jirugi).
6. Exécuter un coup de poing moyen vers D avec le poing droit tout en maintenant la position assise (Annun So Orun Joomuk Kaunde Ap Jirugi).
7. Déplacer le pied droit vers AD pour former une position de marche droite vers AD tout en exécutant un blocage latéral moyen vers AD avec l'avant-bras intérieur droit (Gunnun So An Palmok Kaunde Yop Makgi).
8. Exécuter un coup de pied frontal bas vers AD avec le pied gauche, en conservant la position des mains du mouvement 7 (Najunde Apcha Busigi).
9. Poser le pied gauche au sol vers AD pour former une position de marche gauche vers AD tout en exécutant un coup de poing moyen vers AD avec le poing gauche (Gunnun So Kaunde Jirugi).
10. Exécuter un coup de poing moyen vers AD avec le poing droit tout en maintenant la position de marche gauche (Gunnun So Kaunde Bandae Jirugi).
11. Déplacer le pied gauche vers BD pour former une position de marche gauche vers BD tout en exécutant un blocage latéral moyen vers BD avec l'avant-bras intérieur gauche (Gunnun So An Palmok Kaunde Yop Makgi).
12. Exécuter un coup de pied frontal bas vers BD with le pied droit, en conservant la position des mains du mouvement 11 (Najunde Apcha Busigi).
13. Poser le pied droit au sol vers BD pour former une position de marche droite vers BD tout en exécutant un coup de poing moyen vers BD avec le poing droit (Gunnun So Kaunde Jirugi).
14. Exécuter un coup de poing moyen vers BD avec le poing gauche tout en maintenant la position de marche droite (Gunnun So Kaunde Bandae Jirugi).
15. Exécuter un blocage crochetant moyen vers D avec la paume droite tout en formant une position de marche droite vers D, en pivotant avec le pied gauche (Gunnun So Sonbadak Kaunde Golcho Makgi).
16. Exécuter un blocage crochetant moyen vers D avec la paume gauche tout en maintenant la position de marche droite vers D (Gunnun So Sonbadak Kaunde Bandae Golcho Makgi).
17. Exécuter un coup de poing moyen vers D avec le poing droit tout en maintenant la position de marche droite (Gunnun So Kaunde Jirugi).
18. Déplacer le pied gauche vers D pour former une position de marche gauche vers D tout en exécutant un blocage crochetant moyen vers D avec la paume gauche (Gunnun So Sonbadak Kaunde Golcho Makgi).
19. Exécuter un blocage crochetant moyen vers D avec la paume droite tout en maintenant la position de marche gauche (Gunnun So Sonbadak Kaunde Bandae Golcho Makgi).
20. Exécuter un coup de poing moyen vers D avec le poing gauche tout en maintenant la position de marche gauche (Gunnun So Kaunde Jirugi).
21. Déplacer le pied droit vers D pour former une position de marche droite vers D tout en exécutant un coup de poing moyen vers D avec le poing droit (Gunnun So Kaunde Jirugi).
22. Tourner le visage vers D en formant une position de préparation avec flexion droite A vers D (Guburyo Junbi So A).
23. Exécuter un coup de pied de côté percutant moyen vers D avec le pied gauche (Kaunde Yopcha Jirugi).
24. Poser le pied gauche au sol vers D pour former une position de marche gauche vers D tout en frappant la paume gauche avec le coude frontal droit (Gunnun So Ap Palkup Bandae Taerigi).
25. Tourner le visage vers C en formant une position de préparation avec flexion gauche A vers C (Guburyo Junbi So A).
26. Exécuter un coup de pied de côté percutant moyen vers C avec le pied droit (Kaunde Yopcha Jirugi).
27. Poser le pied droit au sol vers C pour former une position de marche droite vers C tout en frappant la paume droite avec le coude frontal gauche (Gunnun So Ap Palkup Bandae Taerigi).
28. Déplacer le pied gauche vers E pour former une position en L droite vers E tout en exécutant un blocage double avec le tranchant des mains (Niunja So Sang Sonkal Makgi).
29. Avancer le pied droit vers E pour former une position de marche droite vers E tout en exécutant une attaque de pique de la main droite avec l'extrémité des doigts rectilignes (Gunnun So Sun Sonkut Kaunde Tulgi).
30. Déplacer le pied droit vers F, en tournant dans le sens horaire pour former une position en L gauche vers F tout en exécutant un blocage double avec le tranchant des mains (Niunja So Sang Sonkal Makgi).
31. Avancer le pied gauche vers F pour former une position de marche gauche vers F tout en exécutant une attaque de pique de la main gauche avec l'extrémité des doigts rectilignes (Gunnun So Sun Sonkut Kaunde Tulgi).
32. Déplacer le pied gauche vers C pour former une position de marche gauche vers C tout en exécutant un blocage latéral haut vers C avec l'avant-bras extérieur gauche (Gunnun So Bakat Palmok Nopunde Yop Makgi).
33. Exécuter un coup de poing moyen vers C avec le poing droit tout en maintenant la position de marche gauche vers C (Gunnun So Kaunde Bandae Jirugi).
34. Avancer le pied droit vers C pour former une position de marche droite vers C tout en exécutant un blocage latéral haut vers C avec l'avant-bras extérieur droit (Gunnun So Bakat Palmok Nopunde Yop Makgi).
35. Exécuter un coup de poing moyen vers C avec le poing gauche tout en maintenant la position de marche droite (Gunnun So Kaunde Bandae Jirugi).
36. Sauter vers C pour former une position en X gauche vers B tout en exécutant une frappe latérale haute vers C avec le revers du poing gauche (Twigi, Wen Kyocha So Dung Joomuk Nopunde Yop Taerigi).
37. Déplacer le pied droit vers A pour former une position de marche droite vers A tout en exécutant un blocage haut vers A avec le double avant-bras droit (Gunnun So Doo Palmok Nopunde Makgi).
38. Ramener le pied droit vers le pied gauche, puis déplacer le pied gauche vers B pour former une position de marche gauche vers B tout en exécutant un blocage haut vers B avec le double avant-bras gauche (Gunnun So Doo Palmok Nopunde Makgi).

### FIN : Ramener le pied gauche vers la posture de départ (Ready Posture).
