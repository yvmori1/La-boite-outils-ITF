# TOI-GYE

> **Grade :** 3e Gup — Ceinture bleue barre rouge

* **Nombre de mouvements :**  37
* **Diagramme au sol :**  (Hanja pour l'Érudit / Lettré)

| Diagramme | Description |
| ------ | ------ |
| ![**士**](../images/toi-gye.png) | TOI-GYE est le nom de plume du célèbre érudit Yi Hwang (XVIe siècle), une autorité reconnue sur le néo-confucianisme. Les 37 mouvements se rapportent à son lieu de naissance situé sur le 37e degré de latitude, et le diagramme représente l'érudit (lettré). |

[TOI-GYE](https://vimeo.com/96867780)

## Liste Détaillée des Mouvements

### Posture de départ : Position de préparation fermée B (Closed Ready Stance B / Moa Chunbi Sogi B).

1. Déplacer le pied gauche vers B pour former une position en L droite vers B tout en exécutant un blocage moyen vers B avec l'avant-bras intérieur gauche (Niunja So An Palmok Kaunde Makgi).
2. Exécuter une poussée basse vers B avec le bout des doigts de la main droite vers le haut tout en formant une position de marche gauche vers B en faisant glisser le pied gauche (Gunnun So Dwijibun Sonkut Najunde Tulgi).
3. Ramener le pied gauche vers le pied droit pour former une position fermée vers D tout en exécutant une frappe latérale arrière vers C avec le revers du poing droit, et en étendant le bras gauche vers le bas (Moa So Orun Dung Joomuk Yopdwi Taerigi).
4. Déplacer le pied droit vers A pour former une position en L gauche vers A tout en exécutant un blocage moyen vers A avec l'avant-bras intérieur droit (Niunja So An Palmok Kaunde Makgi).
5. Exécuter une poussée basse vers A avec le bout des doigts de la main gauche vers le haut tout en formant une position de marche droite vers A en faisant glisser le pied droit (Gunnun So Dwijibun Sonkut Najunde Tulgi).
6. Ramener le pied droit vers le pied gauche pour former une position fermée vers D tout en exécutant une frappe latérale arrière vers C avec le revers du poing gauche, et en étendant le bras droit vers le bas (Moa So Wen Dung Joomuk Yopdwi Taerigi).
7. Déplacer le pied gauche vers D pour former une position de marche gauche vers D tout en exécutant un blocage pressant avec les poists croisés en X (Gunnun So Kyocha Joomuk Noollo Makgi).
8. Exécuter un coup de poing vertical haut avec double poing vers D tout en maintenant la position de marche gauche (Gunnun So Sang Joomuk Nopunde Sewo Jirugi).
9. Exécuter un coup de pied frontal moyen vers D avec le pied droit, en conservant la position des mains du mouvement 8 (Kaunde Apcha Busigi).
10. Poser le pied droit au sol vers D pour former une position de marche droite vers D tout en exécutant un coup de poing moyen vers D avec le poing droit (Gunnun So Kaunde Jirugi).
11. Exécuter un coup de poing moyen vers D avec le poing gauche tout en maintenant la position de marche droite (Gunnun So Kaunde Bandae Jirugi).
12. Ramener le pied gauche vers le pied droit pour former une position fermée vers F tout en exécutant une frappe de coude latérale double (Moa So Sang Yop Palkup Tulgi).
13. Déplacer le pied droit vers F en frappant le sol du pied pour former une position assise vers C tout en exécutant un blocage en W avec l'avant-bras extérieur droit (Annun So Bakat Palmok San Makgi).
14. Déplacer le pied gauche vers F en frappant le sol du pied et tourner dans le sens horaire pour former une position assise vers D tout en exécutant un blocage en W avec l'avant-bras extérieur gauche (Annun So Bakat Palmok San Makgi).
15. Déplacer le pied gauche vers E en frappant le sol du pied et tourner dans le sens horaire pour former une position assise vers C tout en exécutant un blocage en W avec l'avant-bras extérieur gauche (Annun So Bakat Palmok San Makgi).
16. Déplacer le pied droit vers E en frappant le sol du pied et tourner dans le sens anti-horaire pour former une position assise vers D tout en exécutant un blocage en W avec l'avant-bras extérieur droit (Annun So Bakat Palmok San Makgi).
17. Déplacer le pied gauche vers E en frappant le sol du pied et tourner dans le sens horaire pour former une position assise vers C tout en exécutant un blocage en W avec l'avant-bras extérieur gauche (Annun So Bakat Palmok San Makgi).
18. Déplacer le pied gauche vers F en frappant le sol du pied et tourner dans le sens horaire pour former une position assise vers D tout en exécutant un blocage en W avec l'avant-bras extérieur gauche (Annun So Bakat Palmok San Makgi).
19. Ramener le pied droit vers le pied gauche, puis déplacer le pied gauche vers D pour former une position en L droite vers D tout en exécutant un blocage pressant bas vers D avec le double avant-bras gauche (Niunja So Doo Palmok Najunde Miro Makgi).
20. Étendre les deux mains vers le haut comme pour saisir la tête de l'adversaire tout en formant une position de marche gauche vers D en faisant glisser le pied gauche.
21. Exécuter un coup de genou vers le haut avec le genou droit tout en tirant les deux mains vers le bas (Moorup Ollyo Chagi).
22. Poser le pied droit au sol à côté du pied gauche, puis déplacer le pied gauche vers C pour former une position en L droite vers C tout en exécutant un blocage de garde moyen vers C avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
23. Exécuter un coup de pied frontal de côté bas vers C avec le pied gauche, en conservant la position des mains du mouvement 22 (Najunde Yobap Cha Busigi).
24. Poser le pied gauche au sol vers C pour former une position de marche gauche vers C tout en exécutant une poussée haute vers C avec le bout des doigts à plat gauche (Gunnun So Opun Sonkut Nopunde Tulgi).
25. Déplacer le pied droit vers C pour former une position en L gauche vers C tout en exécutant un blocage de garde moyen vers C avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
26. Exécuter un coup de pied frontal de côté bas vers C avec le pied droit, en conservant la position des mains du mouvement 25 (Najunde Yobap Cha Busigi).
27. Poser le pied droit au sol vers C pour former une position de marche droite vers C tout en exécutant une poussée haute vers C avec le bout des doigts à plat droite (Gunnun So Opun Sonkut Nopunde Tulgi).
28. Déplacer le pied droit vers D pour former une position en L droite vers C tout en exécutant une frappe latérale arrière vers D avec le revers du poing droit et un blocage bas vers C avec l'avant-bras gauche (Niunja So Dung Joomuk Baro Yopdwi Taerigi wa Palmok Najunde Bandae Makgi).
29. Sauter vers C pour former une position en X droite vers A tout en exécutant un blocage pressant avec les poings croisés en X (Twigi, Orun Kyocha So Kyocha Joomuk Noollo Makgi).
30. Déplacer le pied droit vers C pour former une position de marche droite vers C tout en exécutant un blocage haut vers C avec le double avant-bras droit (Gunnun So Doo Palmok Nopunde Makgi).
31. Déplacer le pied gauche vers B pour former une position en L droite vers B tout en exécutant un blocage de garde bas vers B avec le tranchant de la main (Niunja So Sonkal Najunde Daebi Makgi).
32. Exécuter un blocage circulaire vers BD avec l'avant-bras intérieur droit tout en formant une position de marche gauche vers B en faisant glisser le pied gauche (Gunnun So An Palmok Dollimyo Makgi).
33. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers A pour former une position en L gauche vers A tout en exécutant un blocage de garde bas vers A avec le tranchant de la main (Niunja So Sonkal Najunde Daebi Makgi).
34. Exécuter un blocage circulaire vers AD avec l'avant-bras intérieur gauche tout en formant une position de marche droite vers A en faisant glissant le pied droit (Gunnun So An Palmok Dollimyo Makgi).
35. Exécuter un blocage circulaire vers CE avec l'avant-bras intérieur droit tout en formant une position de marche gauche vers CE (Gunnun So An Palmok Dollimyo Makgi).
36. Exécuter un blocage circulaire vers AD avec l'avant-bras intérieur gauche tout en formant une position de marche droite vers A (Gunnun So An Palmok Dollimyo Makgi).
37. Déplacer le pied droit sur la ligne AB pour former une position assise vers D tout en exécutant un coup de poing moyen vers D avec le poing droit (Annun So Orun Joomuk Kaunde Jirugi).

### FIN : Ramener le pied droit vers la posture de départ (Ready Posture).
