# SAJU JIRUGI (EXERCICE FONDAMENTAL — QUATRE DIRECTIONS ATTAQUE)

> **Grade :** 10e Gup — Ceinture blanche

* **Nombre de mouvements :**  14 (Pratiqué à droite et à gauche, soit 7 mouvements par côté)
* **Diagramme au sol :**  (Croix / Quatre directions)

| Diagramme | Description |
| ------ | ------ |
| ![**+**](../images/saju-jirugi.png) | Bien qu'il ne s'agisse pas d'un Tul officiel, Saju Jirugi est un exercice fondamental d'attaque de base pour les débutants, permettant d'apprendre la position de marche (Walking Stance) et le coup de poing moyen. |

[Coup de poing 4 directions](https://vimeo.com/132844679?fl=pl&fe=cm)

## Liste Détaillée des Mouvements

### Posture de départ : Position parallèle de préparation (Parallel Ready Stance / Narani Junbi Sogi).

1. Avancer le pied droit vers D pour former une position de marche droite vers D tout en exécutant un coup de poing moyen vers D avec le poing droit ([Gunnun So Kaunde Jirugi](../Techniques/Gunnun-So-Kaunde-Jirugi.md)).
2. Déplacer le pied droit vers A pour former une position de marche gauche vers B tout en exécutant un blocage bas vers B avec l'avant-bras gauche ([Gunnun So Palmok Najunde Makgi](../Techniques/Gunnun-So-Palmok-Najunde-Makgi.md)).
3. Avancer le pied droit vers B pour former une position de marche droite vers B tout en exécutant un coup de poing moyen vers B avec le poing droit ([Gunnun So Kaunde Jirugi](../Techniques/Gunnun-So-Kaunde-Jirugi.md)).
4. Déplacer le pied droit vers D pour former une position de marche gauche vers C tout en exécutant un blocage bas vers C avec l'avant-bras gauche ([Gunnun So Palmok Najunde Makgi](../Techniques/Gunnun-So-Palmok-Najunde-Makgi.md)).
5. Avancer le pied droit vers C pour former une position de marche droite vers C tout en exécutant un coup de poing moyen vers C avec le poing droit ([Gunnun So Kaunde Jirugi](../Techniques/Gunnun-So-Kaunde-Jirugi.md)).
6. Déplacer le pied droit vers B pour former une position de marche gauche vers A tout en exécutant un blocage bas vers A avec l'avant-bras gauche ([Gunnun So Palmok Najunde Makgi](../Techniques/Gunnun-So-Palmok-Najunde-Makgi.md)).
7. Avancer le pied droit vers A pour former une position de marche droite vers A tout en exécutant un coup de poing moyen vers A avec le poing droit ([Gunnun So Kaunde Jirugi](../Techniques/Gunnun-So-Kaunde-Jirugi.md)).

### FIN : Ramener le pied droit vers l'arrière en posture de départ (Ready Posture).
