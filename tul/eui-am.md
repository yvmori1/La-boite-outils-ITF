# EUI-AM

> **Grade :** 2e Dan

* **Nombre de mouvements :**  45
* **Diagramme au sol :**  (Ligne verticale unique)

| Diagramme | Description |
| ------ | ------ |
| ![**\|**](../images/eui-am.png) | EUI-AM est le pseudonyme de Son Byong Hi, leader du mouvement d'indépendance de la Corée du 1er mars 1919. Les 45 mouvements rappellent son âge lorsqu'il changea le nom de Dong Hak (culture orientale) en Chondo Kyo (religion de la voie céleste) en 1905. Le diagramme symbolise son esprit indomptable. |

## Liste Détaillée des Mouvements

### Posture de départ : Position de préparation fermée D (Closed Ready Stance D / Moa Chunbi Sogi D).

1. Déplacer le pied droit vers C pour former une position de marche gauche vers D tout en exécutant un blocage vers l'intérieur bas vers D avec le tranchant de la main droite (Gunnun So Sonkal Najunde Anuro Makgi).
2. Déplacer le pied gauche vers C pour former une position de marche droite vers D tout en exécutant un blocage de côté haut vers D with l'avant-bras extérieur gauche (Gunnun So Bakat Palmok Nopunde Yop Makgi).
3. Exécuter un coup de poing moyen vers D with le poing droit tout en maintenant la position de marche droite (Gunnun So Kaunde Bandae Jirugi).
4. Exécuter un coup de pied torsadé bas vers D avec le pied gauche, en conservant la position des mains du mouvement 3 (Najunde Bituro Chagi).
5. Poser le pied gauche au sol vers D pour former une position de marche gauche vers D tout en exécutant un blocage vers le bas avec les poignets croisés en X (Gunnun So Kyocha Joomuk Naeryo Makgi).
6. Exécuter un blocage ascendant avec le tranchant de la main droite tout en maintenant la position de marche gauche vers D (Gunnun So Sonkal Chookyo Makgi).
7. Sauter vers D, formant une position en X droite vers BD tout en exécutant une frappe de côté haute vers D avec le revers du poing droit et en amenant le bout des doigts gauches sur le poing droit (Twigi, Orun Kyocha So Dung Joomuk Nopunde Yop Taerigi).
8. Déplacer le pied gauche vers C pour former une position en L droite vers C tout en exécutant un coup de poing moyen vers C avec le poing gauche (Niunja So Kaunde Baro Jirugi).
9. Exécuter un coup de pied circulaire inversé moyen vers AC avec le pied droit (Kaunde Bandae Dollyo Chagi).
10. Poser le pied droit au sol vers C en frappant le sol du pied pour former une position assise vers A tout en exécutant une frappe latérale moyenne vers C avec le tranchant de la main droite (Annun So Sonkal Kaunde Yop Taerigi).
11. Exécuter un coup de pied de côté percutant moyen vers C avec le pied gauche tout en tournant dans le sens horaire et en tirant les deux mains dans la direction opposée (Kaunde Yopcha Jirugi).
12. Poser le pied gauche au sol vers C pour former une position de marche gauche vers C tout en exécutant un coup de poing en croissant haut avec le poing droit (Gunnun So Nopunde Bandal Jirugi).
13. Exécuter un coup de poing circulaire moyen avec le poing gauche tout en formant une position parallèle vers C, ramenant le pied droit (Narani So Kaunde Dollyo Jirugi).
14. Déplacer le pied gauche vers D pour former une position de marche droite vers C tout en exécutant un blocage vers l'intérieur bas avec le tranchant de la main gauche (Gunnun So Sonkal Najunde Anuro Makgi).
15. Déplacer le pied droit vers D pour former une position de marche gauche vers C tout en exécutant un blocage de côté haut vers C avec l'avant-bras extérieur droit (Gunnun So Bakat Palmok Nopunde Yop Makgi).
16. Exécuter un coup de poing moyen vers C avec le poing gauche tout en maintenant la position de marche gauche (Gunnun So Kaunde Bandae Jirugi).
17. Exécuter un coup de pied torsadé bas vers C avec le pied droit, en conservant la position des mains du mouvement 16 (Najunde Bituro Chagi).
18. Poser le pied droit au sol vers C pour former une position de marche droite vers C tout en exécutant un blocage vers le bas avec les poignets croisés en X (Gunnun So Kyocha Joomuk Naeryo Makgi).
19. Exécuter un blocage ascendant avec le tranchant de la main gauche tout en maintenant la position de marche droite (Gunnun So Sonkal Chookyo Makgi).
20. Sauter vers C pour former une position en X gauche vers BC tout en exécutant une frappe de côté haute vers C avec le revers du poing gauche et en amenant le bout des doigts droits sur le poing gauche (Twigi, Wen Kyocha So Dung Joomuk Nopunde Yop Taerigi).
21. Déplacer le pied droit vers D pour former une position en L gauche vers D tout en exécutant un coup de poing moyen vers D avec le poing droit (Niunja So Kaunde Baro Jirugi).
22. Exécuter un coup de pied circulaire inversé moyen vers AD avec le pied gauche (Kaunde Bandae Dollyo Chagi).
23. Poser le pied gauche au sol vers D en frappant le sol du pied pour former une position assise vers A tout en exécutant une frappe latérale moyenne vers D avec le tranchant de la main gauche (Annun So Sonkal Kaunde Yop Taerigi).
24. Exécuter un coup de pied de côté percutant moyen vers D avec le pied droit tout en tournant dans le sens anti-horaire et en tirant les deux mains dans la direction opposée (Kaunde Yopcha Jirugi).
25. Poser le pied droit au sol vers D pour former une position de marche droite vers D tout en exécutant un coup de poing en croissant haut avec le poing gauche (Gunnun So Nopunde Bandal Jirugi).
26. Exécuter un coup de poing circulaire moyen avec le poing droit tout en formant une position parallèle vers D, ramenant le pied gauche (Narani So Kaunde Dollyo Jirugi).
27. Déplacer le pied droit vers D pour former une position de marche droite vers D tout en exécutant un blocage en coin moyen avec le tranchant de la main (Gunnun So Sonkal Kaunde Hechyo Makgi).
28. Exécuter un blocage circulaire vers BD avec le tranchant de la main inversé gauche tout en maintenant la position de marche droite (Gunnun So Sonkal Dung Dollimyo Makgi).
29. Exécuter un blocage bas avec paume alternée tout en formant une position de pied arrière gauche vers D, ramenant le pied droit (Dwitbal So Eotkallyo Sonbadak Naeryo Makgi).
30. Exécuter un coup de poing moyen vers D avec le poing gauche tout en formant une position en L gauche vers D, en faisant glisser le pied droit (Niunja So Kaunde Baro Jirugi).
31. Exécuter un blocage vers l'intérieur bas vers D avec le tranchant de la main inversé droit tout en se déplaçant vers C pour maintenir la position en L gauche vers D (Niunja So Sonkal Dung Najunde Anuro Makgi).
32. Déplacer le pied gauche vers D pour former une position de marche gauche vers D tout en exécutant un blocage en coin moyen avec le tranchant de la main (Gunnun So Sonkal Kaunde Hechyo Makgi).
33. Exécuter un blocage circulaire vers AD avec le tranchant de la main inversé droit tout en maintenant la position de marche gauche (Gunnun So Sonkal Dung Dollimyo Makgi).
34. Exécuter un blocage bas avec paume alternée tout en formant une position de pied arrière droite vers D, ramenant le pied gauche (Dwitbal So Eotkallyo Sonbadak Naeryo Makgi).
35. Exécuter un coup de poing moyen vers D avec le poing droit tout en formant une position en L droite vers D, en faisant glisser le pied gauche (Niunja So Kaunde Baro Jirugi).
36. Exécuter un blocage vers l'intérieur bas vers D avec le tranchant de la main inversé gauche tout en se déplaçant vers C pour maintenir la position en L droite vers D (Niunja So Sonkal Dung Najunde Anuro Makgi).
37. Exécuter un coup de pied circulaire inversé haut vers BD avec le pied droit (Nopunde Bandae Dollyo Chagi).
38. Poser le pied droit au sol vers D pour former une position de pied arrière gauche vers D tout en exécutant un blocage de garde moyen vers D avec l'avant-bras (Dwitbal So Palmok Kaunde Daebi Makgi).
39. Exécuter un coup de pied circulaire inversé haut vers AD avec le pied gauche (Nopunde Bandae Dollyo Chagi).
40. Poser le pied gauche au sol vers D pour former une position de pied arrière droite vers D tout en exécutant un blocage de garde moyen vers D avec l'avant-bras (Dwitbal So Palmok Kaunde Daebi Makgi).
41. Déplacer le pied gauche vers l'arrière de côté du pied droit, puis déplacer le pied droit vers C pour former une position en L droite vers D tout en exécutant un blocage latéral bas vers D avec le tranchant de la main gauche (Niunja So Sonkal Najunde Bakuro Makgi).
42. Exécuter un coup de poing moyen vers D avec le poing droit tout en formant une position de marche gauche vers D, en faisant glisser le pied droit (Gunnun So Kaunde Bandae Jirugi).
43. Déplacer le pied gauche vers C pour former une position en L gauche vers D tout en exécutant un blocage bas vers D avec le tranchant de la main droite (Niunja So Sonkal Najunde Makgi).
44. Exécuter un coup de poing moyen vers D avec le poing gauche tout en formant une position de marche droite vers D, en faisant glisser le pied gauche (Gunnun So Kaunde Bandae Jirugi).
45. Exécuter un coup de poing haut vers D with le poing droit tout en maintenant la position de marche droite vers D (Gunnun So Nopunde Jirugi).

### FIN : Ramener le pied gauche vers la posture de départ (Ready Posture).
