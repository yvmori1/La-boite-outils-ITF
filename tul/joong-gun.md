# JOONG-GUN

> **Grade :** 4e Gup — Ceinture bleue

* **Nombre de mouvements :**  32
* **Diagramme au sol :**  (Hanja ou lettre capitale I)

| Diagramme | Description |
| ------ | ------ |
| ![**I**](../images/joong-gun.png) | JOONG-GUN est nommé d'après le patriote Ahn Joong-Gun qui assassina Hiro-Bumi Ito, le premier gouverneur général japonais de la Corée, connu pour avoir été le principal artisan de la fusion Corée-Japon. Les 32 mouvements de ce Tul représentent l'âge de M. Ahn lorsqu'il fut exécuté à la prison de Lui-Shung en 1910. |

[JOONG-GUN](https://vimeo.com/95926168)

## Liste Détaillée des Mouvements

### Posture de départ : Position de préparation fermée B (Closed Ready Stance B / Moa Chunbi Sogi B).

1. Déplacer le pied gauche vers B pour former une position en L droite vers B tout en exécutant un blocage moyen vers B avec le tranchant de la main inversé gauche (Niunja So Sonkal Dung Kaunde Makgi).
2. Exécuter un coup de pied frontal de côté bas vers B avec le pied gauche, en conservant la position des mains du mouvement 1 (Najunde Yobap Cha Busigi).
3. Poser le pied gauche au sol vers B, puis déplacer le pied droit vers B pour former une position de pied arrière gauche vers B tout en exécutant un blocage ascendant avec la paume droite (Dwitbal So Sonbadak Bandae Ollyo Makgi).
4. Déplacer le pied droit vers A pour former une position en L gauche vers A tout en exécutant un blocage moyen vers A avec le tranchant de la main inversé droit (Niunja So Sonkal Dung Kaunde Makgi).
5. Exécuter un coup de pied frontal de côté bas vers A avec le pied droit, en conservant la position des mains du mouvement 4 (Najunde Yobap Cha Busigi).
6. Poser le pied droit au sol vers A, puis déplacer le pied gauche vers A pour former une position de pied arrière droite vers A tout en exécutant un blocage ascendant avec la paume gauche (Dwitbal So Sonbadak Bandae Ollyo Makgi).
7. Déplacer le pied gauche vers D pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
8. Exécuter un coup de coude ascendant droit tout en formant une position de marche gauche vers D en faisant glisser le pied gauche vers D (Gunnun So Wi Palkup Bandae Taerigi).
9. Déplacer le pied droit vers D pour former une position en L gauche vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
10. Exécuter un coup de coude ascendant gauche tout en formant une position de marche droite vers D en faisant glisser le pied droit vers D (Gunnun So Wi Palkup Bandae Taerigi).
11. Déplacer le pied gauche vers D pour former une position de marche gauche vers D tout en exécutant un coup de poing vertical haut avec double poing vers D (Gunnun So Sang Joomuk Nopunde Sewo Jirugi).
12. Avancer le pied droit vers D pour former une position de marche droite vers D tout en exécutant un coup de poing remontant avec double poing vers D (Gunnun So Sang Joomuk Dwijibo Jirugi).
13. Déplacer le pied droit sur la ligne CD, puis tourner dans le sens anti-horaire pour former une position de marche gauche vers C tout en exécutant un blocage ascendant avec les poignets croisés en X (Gunnun So Kyocha Joomuk Chookyo Makgi).
14. Déplacer le pied gauche vers E pour former une position en L droite vers E tout en exécutant une frappe latérale haute vers E avec le revers du poing gauche (Niunja So Dung Joomuk Nopunde Yop Taerigi).
15. Pivoter le poing gauche vers le bas (dans le sens anti-horaire) tout en faisant glisser le pied gauche vers E pour former une position de marche gauche vers E.
16. Exécuter un coup de poing haut vers E with le poing droit tout en maintenant la position de marche gauche vers E (Gunnun So Nopunde Bandae Jirugi).
17. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers F pour former une position en L gauche vers F tout en exécutant une frappe latérale haute vers F avec le revers du poing droit (Niunja So Dung Joomuk Nopunde Yop Taerigi).
18. Pivoter le poing droit vers le bas (dans le sens horaire) tout en faisant glisser le pied droit vers F pour former une position de marche droite vers F.
19. Exécuter un coup de poing haut vers F avec le poing gauche tout en maintenant la position de marche droite (Gunnun So Nopunde Bandae Jirugi).
20. Ramener le pied droit vers le pied gauche, puis déplacer le pied gauche vers C pour former une position de marche gauche vers C tout en exécutant un blocage haut vers C avec le double avant-bras gauche (Gunnun So Doo Palmok Nopunde Makgi).
21. Exécuter un coup de poing moyen vers C with le poing gauche tout en ramenant légèrement le pied gauche pour former une position en L droite vers C (Niunja So Kaunde Yop Jirugi).
22. Exécuter un coup de pied de côté percutant moyen vers C avec le pied droit (Kaunde Yopcha Jirugi).
23. Poser le pied droit au sol vers C pour former une position de marche droite vers C tout en exécutant un blocage haut vers C avec le double avant-bras droit (Gunnun So Doo Palmok Nopunde Makgi).
24. Exécuter un coup de poing moyen vers C with le poing droit tout en ramenant légèrement le pied droit pour former une position en L gauche vers C (Niunja So Kaunde Yop Jirugi).
25. Exécuter un coup de pied de côté percutant moyen vers C avec le pied gauche (Kaunde Yopcha Jirugi).
26. Poser le pied gauche au sol vers C pour former une position en L droite vers C tout en exécutant un blocage de garde moyen vers C with l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
27. Exécuter un blocage pressant avec la paume droite tout en faisant glisser le pied gauche vers C pour former une position basse gauche vers C (Nachuo So Sonbadak Bandae Noollo Makgi).
28. Avancer le pied droit vers C pour former une position en L gauche vers C tout en exécutant un blocage de garde moyen vers C with l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
29. Exécuter un blocage pressant avec la paume gauche tout en faisant glisser le pied droit vers C pour former une position basse droite vers C (Nachuo So Sonbadak Bandae Noollo Makgi).
30. Ramener le pied gauche vers le pied droit pour former une position fermée vers A tout en exécutant un coup de poing angulaire avec le poing droit (Moa So Orun Giokja Jirugi).
31. Déplacer le pied droit vers A pour former une position fixe droite vers A tout en exécutant un blocage en U vers A (Gojung So Digutja Makgi).
32. Ramener le pied droit vers le pied gauche, puis déplacer le pied gauche vers B pour former une position fixe gauche vers B tout en exécutant un blocage en U vers B (Gojung So Digutja Makgi).

### FIN : Ramener le pied gauche vers la posture de départ (Ready Posture).
