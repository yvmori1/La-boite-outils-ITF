# UL-JI

> **Grade :** 4e Dan

* **Nombre de mouvements :**  42
* **Diagramme au sol :**  (En forme de Z inversé/caractère 乙)

| Diagramme | Description |
| ------ | ------ |
| ![**Hanja pour le nom de famille (Moon-Dok)**](../images/ul-ji.png) | UL-JI est nommé d'après le général Ul-Ji Moon Dok qui défendit la Corée avec succès en 612 apr. J.-C. contre un million de soldats chinois de la dynastie Sui, dirigés par Yang Je. En employant des tactiques de guérilla d'usure de type harcèlement rapide, Ul-Ji parvint à décimer une grande partie des forces ennemies. Le diagramme représente son nom de famille. Les 42 mouvements correspondent à l'âge du Général Choi Hong Hi lorsqu'il créa ce Tul. |

## Liste Détaillée des Mouvements

### Posture de départ : Position parallèle avec revers croisés en X (Parallel Stance with an X-Back Hand / Narani Sogi Ssang Joomuk).

1. Déplacer le pied gauche vers C pour former une position de marche droite vers D tout en exécutant une frappe horizontale avec double poing latéral (Gunnun So Sang Yop Joomuk Soopyong Taerigi).
2. Déplacer le pied droit vers C pour former une position de marche gauche vers D tout en exécutant un blocage pressant avec les poignets croisés en X (Gunnun So Kyocha Joomuk Noollo Makgi).
3. Exécuter un blocage ascendant avec les mains croisées en X avec le tranchant des mains tout en maintenant la position de marche gauche (Gunnun So Kyocha Sonkal Chookyo Makgi).
4. Exécuter une frappe frontale haute vers D avec le tranchant de la main droite tout en amenant la paume gauche sur l'articulation du coude droit, en maintenant la position de marche gauche vers D (Gunnun So Sonkal Nopunde Ap Taerigi).
5. Déplacer le pied gauche vers C pour former une position assise vers B tout en exécutant une frappe horizontale vers C avec le revers de la main gauche (Annun So Sondung Soopyong Taerigi).
6. Exécuter un coup de pied en croissant moyen sur la paume gauche avec le pied droit (Kaunde Bandal Chagi).
7. Poser le pied droit au sol vers C pour former une position assise vers A tout en frappant la paume gauche avec le coude frontal droit (Annun So Ap Palkup Taerigi).
8. Pousser vers B avec le coude arrière gauche tout en plaçant le poing droit (côté) sur le poing gauche, maintenant la position assise vers A (Annun So Dwit Palkup Tulgi).
9. Exécuter une frappe de côté arrière vers B avec le revers du poing droit et étendre le bras gauche vers le bas de côté tout en maintenant la position assise vers A (Annun So Dung Joomuk Yopdwi Taerigi).
10. Ramener le pied gauche vers le pied droit pour former une position fermée vers D tout en poussant avec double coude latéral (Moa So Sang Yop Palkup Tulgi).
11. Glisser le pied gauche vers le pied droit pour former une position fermée vers D tout en tournant le visage vers A et en maintenant la position des mains (Moa Sogi).
12. Exécuter un coup de pied de côté percutant moyen vers A avec le pied droit, en conservant la position des mains (Kaunde Yopcha Jirugi).
13. Poser le pied droit au sol vers A, puis croiser le pied gauche par-dessus le pied droit pour former une position en X droite vers D tout en exécutant une poussée horizontale avec double coude (Orun Kyocha So Sang Palkup Soopyong Tulgi).
14. Déplacer le pied droit vers A pour former une position assise vers D tout en exécutant un coup de poing horizontal droit vers A (Annun So Orun Soopyong Jirugi).
15. Exécuter une frappe frontale haute vers D avec le tranchant de la main droite tout en amenant le revers de la main gauche au-dessus du front tout en se redressant vers D (Sonkal Nopunde Ap Taerigi).
16. Exécuter un blocage double avec le tranchant des mains vers B tout en formant une position en L droite vers B, en pivotant sur le pied droit (Niunja So Sang Sonkal Makgi).
17. Sauter pour exécuter un coup de pied de côté en plein vol vers B avec le pied droit tout en tournant dans le sens horaire (Twimyo Yopcha Jirugi).
18. Atterrir vers B pour former une position de marche droite vers B tout en exécutant un blocage moyen vers B avec le double avant-bras droit (Gunnun So Doo Palmok Kaunde Makgi).
19. Ramener le pied gauche vers le pied droit pour former une position de préparation fermée B vers D (Moa Junbi So B).
20. Sauter vers D pour former une position en X droite vers BD tout en exécutant une frappe de côté haute vers B avec le revers du poing droit et en amenant le bout des doigts gauches sur le poing droit (Twigi, Orun Kyocha So Dung Joomuk Nopunde Yop Taerigi).
21. Déplacer le pied gauche vers C pour former une position de marche droite vers D tout en exécutant un blocage ascendant avec l'avant-bras gauche (Gunnun So Palmok Chookyo Makgi).
22. Exécuter un coup de pied frontal moyen vers D with le pied gauche, en conservant la position des mains (Kaunde Apcha Busigi).
23. Poser le pied gauche au sol vers D pour former une position de marche gauche vers D tout en exécutant un coup de poing haut vers D avec le poing droit (Gunnun So Nopunde Bandae Jirugi).
24. Déplacer le pied droit vers D pour former une position de marche droite vers D tout en exécutant une poussée moyenne vers D avec le bout des doigts rectilignes droit (Gunnun So Sun Sonkut Kaunde Tulgi).
25. Déplacer le pied gauche vers D, en tournant dans le sens anti-horaire pour former une position assise vers A tout en exécutant une frappe de côté haute vers D avec le revers du poing gauche (Annun So Dung Joomuk Nopunde Yop Taerigi).
26. Déplacer le pied droit vers F, en tournant dans le sens anti-horaire pour former une position de préparation de marche droite vers F (Gunnun Junbi Sogi).
27. Sauter pour exécuter un coup de pied frontal volant haut vers F avec le pied droit (Twimyo Nopi Ap Chagi).
28. Atterrir vers F pour former une position fixe droite vers F tout en exécutant un blocage de contrôle vers F avec les mains croisées en X avec le tranchant des mains (Gojung So Kyocha Sonkal Momchau Makgi).
29. Déplacer le pied gauche vers F pour former une position en L droite vers F tout en exécutant un blocage pressant avec les poignets croisés en X (Niunja So Kyocha Joomuk Noollo Makgi).
30. Exécuter un coup de pied de côté frontal moyen vers F with le pied gauche tout en exécutant un blocage en coin moyen avec l'avant-bras intérieur (Kaunde Yobap Cha Busigi, An Palmok Kaunde Hechyo Makgi).
31. Poser le pied gauche au sol vers F pour former une position de marche gauche vers F tout en exécutant un coup de poing vertical haut avec double poing vers F (Gunnun So Sang Joomuk Nopunde Sewo Jirugi).
32. Déplacer le pied droit vers F pour former une position fixe droite vers F tout en exécutant un blocage de côté moyen vers F with le tranchant de la main droite et un blocage pressant moyen vers F with la paume gauche (Gojung So Sonkal Kaunde Yop Makgi, Sonbadak Kaunde Noollo Makgi).
33. Glisser vers F pour former une position en L droite vers F tout en exécutant un coup de poing moyen vers F with le poing gauche (Niunja So Kaunde Jirugi).
34. Déplacer le pied gauche vers l'arrière de côté du pied droit, puis déplacer le pied droit vers E pour former une position en L droite vers F, puis sauter vers E en maintenant la position en L droite vers F tout en exécutant un blocage de garde moyen vers F with l'avant-bras (Twigi, Niunja So Palmok Kaunde Daebi Makgi).
35. Exécuter un coup de pied circulaire moyen vers DF avec le pied droit (Kaunde Dollyo Chagi).
36. Poser le pied droit au sol vers F, puis exécuter un coup de pied arrière percutant moyen vers F avec le pied gauche (Kaunde Dwitcha Jirugi).
37. Poser le pied gauche au sol vers F pour former une position en L droite vers F tout en exécutant un blocage de garde moyen vers F with l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
38. Déplacer le pied gauche vers E pour former une position en L gauche vers F tout en exécutant un blocage ascendant vers F with la paume droite (Niunja So Sonbadak Ollyo Makgi).
39. Déplacer le pied droit vers E pour former une position de marche droite vers E tout en exécutant un blocage circulaire vers ED with l'avant-bras intérieur gauche (Gunnun So An Palmok Dollimyo Makgi).
40. Exécuter un blocage circulaire vers DE avec l'avant-bras intérieur droit tout en formant une position de marche droite vers DF (Gunnun So An Palmok Dollimyo Makgi).
41. Déplacer le pied gauche sur la ligne EF pour former une position assise vers D tout en exécutant un coup de poing moyen vers D avec le poing gauche (Annun So Kaunde Jirugi).
42. Exécuter un coup de poing moyen vers D avec le poing droit tout en maintenant la position assise vers D (Annun So Kaunde Jirugi).

### FIN : Ramener le pied gauche vers la posture de départ (Ready Posture).
