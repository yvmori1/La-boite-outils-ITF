# GE-BAEK

> **Grade :** 1er Dan

* **Nombre de mouvements :**  44
* **Diagramme au sol :**  (Ligne verticale unique)

## Liste Détaillée des Mouvements

### Posture de départ : Position parallèle de préparation (Parallel Ready Stance / Narani Junbi Sogi).

1. Déplacer le pied droit vers C pour former une position en L droite vers D tout en exécutant un blocage de contrôle vers D avec les poignets croisés en X avec le tranchant des mains (Niunja So Kyocha Sonkal Momchau Makgi).
2. Exécuter un coup de pied torsadé bas vers D avec le pied droit, en conservant la position des mains du mouvement 1 (Najunde Bituro Chagi).
3. Poser le pied droit au sol vers D pour former une position de marche droite vers D tout en exécutant un coup de poing moyen vers D avec le poing droit (Gunnun So Kaunde Jirugi).
4. Exécuter un coup de poing moyen vers D avec le poing gauche tout en maintenant la position de marche droite (Gunnun So Kaunde Bandae Jirugi).
5. Déplacer le pied droit vers C pour former une position de marche gauche vers D tout en exécutant un blocage ascendant avec l'avant-bras gauche (Gunnun So Palmok Chookyo Makgi).
6. Exécuter un blocage bas vers D avec l'avant-bras gauche tout en maintenant la position de marche gauche (Gunnun So Palmok Najunde Makgi).
7. Exécuter un blocage haut vers AD avec double main en arc tout en regardant à travers, maintenant la position de marche gauche vers D (Gunnun So Nopunde Doo Bandalson Makgi).
8. Tourner le visage vers D en formant une position de préparation avec flexion droite A (Right Bending Ready Stance A) vers D.
9. Poser le pied gauche au sol vers AD pour former une position assise vers AC tout en exécutant un blocage écopes vers AC avec la paume gauche (Annun So Wen Sonbadak Duro Makgi).
10. Exécuter un coup de poing moyen vers AC avec le poing droit tout en maintenant la position assise vers AC (Annun So Orun Joomuk Kaunde Jirugi).
11. Exécuter une frappe frontale vers AC avec le revers du poing gauche tout en maintenant la position assise vers AC (Annun So Wen Dung Joomuk Ap Taerigi).
12. Déplacer le pied droit sur la ligne AB, puis déplacer le pied gauche vers C pour former une position en L droite vers C tout en exécutant un blocage de garde moyen vers C avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
13. Exécuter un coup de pied frontal de côté bas vers C avec le pied gauche, en conservant la position des mains du mouvement 12 (Najunde Yobap Cha Busigi).
14. Poser le pied gauche au sol vers C pour former une position basse gauche vers C tout en exécutant une poussée haute vers C avec le bout des doigts à plat gauche (Nachuo So Opun Sonkut Nopunde Tulgi).
15. Exécuter une poussée haute vers C avec le bout des doigts à plat droite tout en maintenant la position basse gauche vers C (Nachuo So Opun Sonkut Nopunde Bandae Tulgi).
16. Exécuter un coup de pied de côté percutant moyen vers C avec le pied droit tout en tirant les deux mains dans la direction opposée (Kaunde Yopcha Jirugi).
17. Poser le pied droit au sol vers C pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
18. Déplacer le pied droit vers D en tournant dans le sens anti-horaire pour former une position en L droite vers C tout en exécutant un blocage de garde moyen vers C avec l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
19. Déplacer le pied gauche vers D en tournant dans le sens anti-horaire pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
20. Déplacer le pied gauche sur la ligne CD pour former une position assise vers A tout en exécutant un blocage en forme de 9 droit (Annun So Orun Gutja Makgi).
21. Déplacer le pied droit vers D, en tournant dans le sens anti-horaire pour former une position de marche gauche vers C tout en exécutant un blocage bas vers C avec le tranchant de la main gauche (Gunnun So Sonkal Najunde Makgi).
22. Exécuter un coup de pied circulaire moyen vers BC avec le pied droit, puis poser le pied au sol vers C (Kaunde Dollyo Chagi).
23. Exécuter un coup de pied de côté percutant sauté vers C avec le pied droit (Twimyo Yopcha Jirugi).
24. Atterrir vers C pour former une position de marche droite vers C tout en exécutant un coup de poing vertical haut avec double poing vers C (Gunnun So Sang Joomuk Nopunde Sewo Jirugi).
25. Exécuter un blocage haut vers AC avec double main en arc tout en regardant à travers, maintenant la position de marche droite vers C (Gunnun So Nopunde Doo Bandalson Makgi).
26. Exécuter un coup de poing remontant vers C avec le poing gauche tout en maintenant la position de marche droite (Gunnun So Bandae Dwijibo Jirugi).
27. Déplacer le pied droit sur la ligne CD, formant une position de marche gauche vers D tout en frappant la paume gauche avec le coude frontal droit (Gunnun So Ap Palkup Bandae Taerigi).
28. Sauter vers D pour former une position en X droite (Right X-Stance) vers BD tout en exécutant un blocage haut vers D avec le double avant-bras droit.
29. Déplacer le pied gauche vers BC pour former une position assise vers BD, tout en exécutant un blocage écopes vers BD avec la paume droite.
30. Exécuter un coup de poing moyen vers BD avec le poing gauche tout en maintenant la position assise vers BD (exécuter 29 et 30 en mouvement connecté).
31. Exécuter une frappe frontale vers BD avec le revers du poing droit tout en maintenant la position assise vers BD.
32. Déplacer le pied gauche vers C pour former une position de marche gauche vers C tout en exécutant une frappe frontale haute vers C avec le tranchant de la main inversé droit.
33. Déplacer le pied gauche vers A d'environ une demi-largeur d'épaule tout en exécutant un coup de pied circulaire moyen vers C avec le pied droit.
34. Poser le pied droit au sol vers C, puis tourner dans le sens anti-horaire pour former une position de marche gauche vers D, en pivotant sur le pied droit tout en exécutant un coup de poing vertical haut avec double poing vers D.
35. Exécuter un coup de poing moyen avec l'articulation du majeur droit (Middle Knuckle Fist) tout en ramenant le poing gauche devant l'épaule droite pour former une position en L droite vers D en ramenant le pied gauche.
36. Déplacer le pied droit vers D pour former une position assise vers B tout en exécutant un blocage en forme de 9 gauche (Left 9-Shape Block).
37. Exécuter un blocage de garde bas vers C avec le tranchant de la main inversé tout en maintenant la position assise vers B.
38. Exécuter un blocage de garde bas vers D avec le tranchant de la main tout en maintenant la position assise vers B (exécuter 37 et 38 en mouvement continu).
39. Déplacer le pied gauche vers D en frappant le sol du pied pour former une position assise vers A tout en exécutant un blocage en W (W-Shape Block) avec l'avant-bras extérieur.
40. Déplacer le pied gauche vers C en frappant le sol du pied pour former une position assise vers B tout en exécutant un blocage en W avec l'avant-bras extérieur.
41. Déplacer le pied droit vers C pour former une position de marche droite vers C tout en exécutant un blocage ascendant avec l'avant-bras droit.
42. Exécuter un coup de poing moyen vers C avec le poing gauche tout en maintenant la position de marche droite.
43. Déplacer le pied droit sur la ligne CD pour former une position de marche gauche vers D tout en exécutant un blocage ascendant avec l'avant-bras gauche.
44. Exécuter un coup de poing moyen vers D with le poing droit tout en maintenant la position de marche gauche.

### FIN : Ramener le pied droit vers la posture de départ (Ready Posture).
