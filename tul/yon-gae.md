# YONG-GAE

> **Grade :** 4e Dan

* **Nombre de mouvements :**  49
* **Diagramme au sol :**  (Hanja ou lettre capitale I)

| Diagramme | Description |
| ------ | ------ |
| ![**I**](../images/yon-gae.png) | YONG-GAE est nommé d'après le célèbre général Yon Gae Somoon de la dynastie Koguryo. Les 49 mouvements représentent l'année 649 apr. J.-C., lorsqu'il détruisit l'armée impériale chinoise des Tang forte de près de 300 000 soldats à Ansi Sung, les obligeant à battre en retraite et à quitter la Corée. |

## Liste Détaillée des Mouvements

### Posture de départ : Position de préparation du guerrier A (Warrior Ready Stance A / Moesa Chunbi Sogi A).

1. Glisser vers C pour former une position en L droite vers D tout en exécutant un blocage de garde bas vers D avec le tranchant de la main inversé, exécuté en décrivant un cercle (Niunja So Sonkal Dung Najunde Daebi Makgi).
2. Exécuter un coup de poing haut vers D with le poing long droit tout en formant une position de marche gauche vers D, en pivotant sur le pied gauche (Gunnun So Ghin Joomuk Nopunde Jirugi).
3. Glisser vers C pour former une position en L gauche vers D tout en exécutant un blocage de garde moyen vers D with l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
4. Exécuter une frappe vers l'extérieur moyenne vers D avec le tranchant de la main droite tout en sautant vers D, puis atterrir vers D pour former une position en L gauche vers D avec le tranchant de la main droite étendu vers D (Twigi, Niunja So Sonkal Kaunde Bakuro Taerigi).
5. Se déplacer vers C tout en maintenant la position en L gauche vers D tout en exécutant un blocage de contrôle vers D with les poignets croisés en X (Niunja So Kyocha Joomuk Momchau Makgi).
6. Exécuter une frappe croisée haute vers l'extérieur vers D with le bout des doigts à plat droite tout en formant une position de marche droite vers D, en faisant glisser le pied droit (Gunnun So Opun Sonkut Nopunde Bakuro Ghutgi).
7. Exécuter une poussée vers le bas avec le coude droit rectiligne tout en formant une position de pied arrière gauche vers D, en ramenant le pied droit (Dwitbal So Sun Palkup Naeryo Tulgi).
8. Sauter vers D pour former une position en X gauche vers AD tout en exécutant une frappe de côté haute vers D avec le revers du poing gauche (Twigi, Wen Kyocha So Dung Joomuk Nopunde Yop Taerigi).
9. Déplacer le pied droit vers C pour former une position de marche gauche vers D tout en exécutant un blocage bas de côté vers D with le tranchant de la main droite (Gunnun So Sonkal Najunde Bakuro Makgi).
10. Déplacer le pied droit sur la ligne AB pour former une position parallèle vers D tout en exécutant un blocage crochetant moyen vers D avec la paume gauche (Narani So Sonbadak Kaunde Golcho Makgi).
11. Exécuter un coup de poing moyen vers D with le poing droit tout en maintenant la position parallèle vers D (Narani So Kaunde Jirugi).
12. Glisser vers C pour former une position en L gauche vers D tout en exécutant un blocage de garde bas vers D avec le tranchant de la main inversé gauche, exécuté en décrivant un cercle (Niunja So Sonkal Dung Najunde Daebi Makgi).
13. Exécuter un coup de poing haut vers D with le poing long gauche tout en formant une position de marche droite vers D, en pivotant sur le pied droit (Gunnun So Ghin Joomuk Nopunde Jirugi).
14. Glisser vers C pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
15. Exécuter une frappe vers l'extérieur moyenne vers D with le tranchant de la main gauche tout en sautant vers D, puis atterrir vers D pour former une position en L droite vers D avec le tranchant de la main gauche étendu vers D (Twigi, Niunja So Sonkal Kaunde Bakuro Taerigi).
16. Se déplacer vers C tout en maintenant la position en L droite vers D tout en exécutant un blocage de contrôle vers D avec les poignets croisés en X (Niunja So Kyocha Joomuk Momchau Makgi).
17. Exécuter une frappe croisée haute vers l'extérieur vers D with le bout des doigts à plat gauche tout en formant une position de marche gauche vers D, en faisant glisser le pied gauche (Gunnun So Opun Sonkut Nopunde Bakuro Ghutgi).
18. Exécuter une poussée vers le bas avec le coude gauche rectiligne tout en formant une position de pied arrière droite vers D, en ramenant le pied gauche (Dwitbal So Sun Palkup Naeryo Tulgi).
19. Sauter vers D pour former une position en X droite vers D tout en exécutant une frappe de côté haute vers A avec le revers du poing droit (Twigi, Orun Kyocha So Dung Joomuk Nopunde Yop Taerigi).
20. Déplacer le pied gauche vers C pour former une position de marche droite vers D tout en exécutant un blocage bas de côté vers D with le tranchant de la main gauche (Gunnun So Sonkal Najunde Bakuro Makgi).
21. Déplacer le pied gauche sur la ligne AB pour former une position parallèle vers D tout en exécutant un blocage crochetant moyen vers D avec la paume droite (Narani So Sonbadak Kaunde Golcho Makgi).
22. Exécuter un coup de poing moyen vers D avec le poing gauche tout en maintenant la position parallèle (Narani So Kaunde Jirugi).
23. Déplacer le pied droit vers A pour former une position assise vers D tout en exécutant un blocage en W with le tranchant de la main inversé (Annun So Sonkal Dung San Makgi).
24. Croiser le pied gauche par-dessus le pied droit pour former une position en X droite vers D tout en exécutant une poussée horizontale avec double coude (Orun Kyocha So Sang Palkup Soopyong Tulgi).
25. Déplacer le pied droit vers A pour former une position assise vers D tout en exécutant un blocage de contrôle vers D with le double avant-bras droit rectiligne (Annun So Doo Sun Palmok Momchau Makgi).
26. Croiser le pied gauche par-dessus le pied droit pour former une position en X droite vers D tout en exécutant un coup de poing ascendant avec le poing droit et en ramenant le poing gauche devant l'épaule droite (Orun Kyocha So Ollyo Jirugi).
27. Exécuter un coup de pied crocheté inversé haut vers B avec le pied droit (Nopunde Bandae Dollyo Goro Chagi).
28. Poser le pied droit au sol vers B, puis exécuter un coup de pied de côté percutant haut vers B with le pied gauche tout en tirant les deux poings devant la poitrine et en tournant dans le sens horaire (Nopunde Yopcha Jirugi).
29. Poser le pied gauche au sol vers B dans un mouvement sauté pour former une position en X gauche vers D tout en exécutant une frappe vers le bas vers B avec le revers du poing gauche (Twigi, Wen Kyocha So Dung Joomuk Naeryo Taerigi).
30. Déplacer le pied gauche vers B pour former une position assise vers D tout en exécutant un blocage en W with le tranchant de la main inversé (Annun So Sonkal Dung San Makgi).
31. Croiser le pied droit par-dessus le pied gauche pour former une position en X gauche vers D tout en exécutant une poussée horizontale avec double coude (Wen Kyocha So Sang Palkup Soopyong Tulgi).
32. Déplacer le pied gauche vers B pour former une position assise vers D tout en exécutant un blocage de contrôle vers D with le double avant-bras gauche rectiligne (Annun So Doo Sun Palmok Momchau Makgi).
33. Croiser le pied droit par-dessus le pied gauche pour former une position en X gauche vers D tout en exécutant un coup de poing ascendant avec le poing gauche et en ramenant le poing droit devant l'épaule gauche (Wen Kyocha So Ollyo Jirugi).
34. Exécuter un coup de pied crocheté inversé haut vers A with le pied gauche (Nopunde Bandae Dollyo Goro Chagi).
35. Poser le pied gauche au sol vers A, puis exécuter un coup de pied de côté percutant haut vers A with le pied droit tout en tirant les deux poings devant la poitrine et en tournant dans le sens anti-horaire (Nopunde Yopcha Jirugi).
36. Poser le pied droit au sol vers A dans un mouvement sauté pour former une position en X droite vers AD tout en exécutant une frappe vers le bas vers A avec le revers du poing droit (Twigi, Orun Kyocha So Dung Joomuk Naeryo Taerigi).
37. Déplacer le pied gauche vers C pour former une position en L gauche vers D tout en exécutant un blocage de garde moyen vers D with l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
38. Déplacer le pied gauche vers D en tournant dans le sens anti-horaire pour former une position de pied arrière gauche vers C tout en exécutant un blocage de hanche vers C with l'avant-bras intérieur droit (Dwitbal So Hori Makgi).
39. Déplacer légèrement le pied droit vers C, puis le pied gauche vers D en frappant le sol du pied pour former une position en L droite vers D tout en exécutant une frappe de côté haute vers D with le tranchant de la main gauche (Niunja So Sonkal Nopunde Yop Taerigi).
40. Se déplacer vers C tout en maintenant la position en L droite vers D tout en exécutant un blocage de garde moyen vers D with l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
41. Déplacer le pied droit vers D en tournant dans le sens horaire pour former une position de pied arrière droite vers C tout en exécutant un blocage de hanche vers C avec l'avant-bras intérieur gauche (Dwitbal So Hori Makgi).
42. Déplacer légèrement le pied gauche vers C, puis le pied droit vers D en frappant le sol du pied pour former une position en L gauche vers D tout en exécutant une frappe de côté haute vers D with le tranchant de la main droite (Niunja So Sonkal Nopunde Yop Taerigi).
43. Déplacer le pied droit vers C en tournant dans le sens anti-horaire pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
44. Sauter pour exécuter un coup de pied de côté en plein vol vers D avec le pied droit tout en tournant dans le sens horaire, puis atterrir vers D pour former une position en L gauche vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Twimyo Yopcha Jirugi, Niunja So Sonkal Kaunde Daebi Makgi).
45. Sauter pour exécuter un coup de pied de côté en plein vol vers D avec le pied gauche tout en tournant dans le sens anti-horaire, puis atterrir vers D pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Twimyo Yopcha Jirugi, Niunja So Sonkal Kaunde Daebi Makgi).
46. Exécuter un blocage vers l'intérieur bas vers D avec le tranchant de la main inversé droit tout en tirant le poing gauche devant l'épaule droite, formant une position de marche gauche vers D en faisant glisser le pied droit vers C (Gunnun So Sonkal Dung Najunde Anuro Makgi).
47. Glisser vers C pour former une position en L gauche vers D tout en poussant vers C with le coude latéral gauche (Niunja So Yop Palkup Tulgi).
48. Exécuter un blocage vers l'intérieur bas vers D avec le tranchant de la main inversé gauche tout en tirant le poing droit devant l'épaule gauche, formant une position de marche droite vers D en faisant glisser le pied gauche vers C (Gunnun So Sonkal Dung Najunde Anuro Makgi).
49. Glisser vers C pour former une position en L droite vers D tout en poussant vers C with le coude latéral droit (Niunja So Yop Palkup Tulgi).

### FIN : Ramener le pied droit vers la posture de départ (Ready Posture).
