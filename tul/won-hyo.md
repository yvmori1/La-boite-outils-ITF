# WON-HYO

> **Grade :** 6e Gup — Ceinture verte

* **Nombre de mouvements :**  28
* **Diagramme au sol :**  (Hanja ou lettre capitale I)

| ![**I**](../images/won-hyo.png) | WON-HYO fut le moine célèbre qui introduisit le bouddhisme sous la dynastie Silla en l'an 686. |

## Liste Détaillée des Mouvements

### Posture de départ : Position de préparation fermée A (Closed Ready Stance A / Moa Chunbi Sogi A).

1. Déplacer le pied gauche vers B pour former une position en L droite vers B tout en exécutant un blocage double de l'avant-bras (Niunja So Sang Palmok Makgi).
2. Exécuter une frappe vers l'intérieur haute vers B avec le tranchant de la main droite tout en amenant le poing gauche (revers) devant l'épaule droite, maintenant la position en L droite (Niunja So Sonkal Nopunde Anuro Taerigi).
3. Exécuter un coup de poing moyen vers B avec le poing gauche tout en glissant le pied gauche vers B pour former une position fixe gauche vers B (Gojung So Kaunde Yop Jirugi).
4. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers A pour former une position en L gauche vers A tout en exécutant un blocage double de l'avant-bras (Niunja So Sang Palmok Makgi).
5. Exécuter une frappe vers l'intérieur haute vers A avec le tranchant de la main gauche tout en amenant le poing droit devant l'épaule gauche, maintenant la position en L gauche (Niunja So Sonkal Nopunde Anuro Taerigi).
6. Exécuter un coup de poing moyen vers A avec le poing droit tout en glissant le pied droit vers A pour former une position fixe droite vers A (Gojung So Kaunde Yop Jirugi).
7. Ramener le pied droit vers le pied gauche, puis tourner le visage vers D tout en formant une position de préparation avec flexion droite A vers D (Guburyo Junbi So A).
8. Exécuter un coup de pied de côté percutant moyen vers D avec le pied gauche (Kaunde Yopcha Jirugi).
9. Poser le pied gauche au sol vers D pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
10. Avancer le pied droit vers D pour former une position en L gauche vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
11. Avancer le pied gauche vers D pour former une position en L droite vers D tout en exécutant un blocage de garde moyen vers D avec le tranchant de la main (Niunja So Sonkal Kaunde Daebi Makgi).
12. Avancer le pied droit vers D pour obtenir une position de marche droite vers D tout en exécutant un coup de pique de la main droite avec l'extrémité des doigts rectilignes (Gunnun So Sun Sonkut Kaunde Tulgi).
13. Déplacer le pied gauche vers E, en tournant dans le sens anti-horaire pour former une position en L droite vers E tout en exécutant un blocage double de l'avant-bras (Niunja So Sang Palmok Makgi).
14. Exécuter une frappe vers l'intérieur haute vers E avec le tranchant de la main droite tout en ramenant le poing gauche devant l'épaule droite, maintenant la position en L droite (Niunja So Sonkal Nopunde Anuro Taerigi).
15. Exécuter un coup de poing moyen vers E avec le poing gauche tout en glissant le pied gauche vers E pour former une position fixe gauche vers E (Gojung So Kaunde Yop Jirugi).
16. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers F pour former une position en L gauche vers F tout en exécutant un blocage double de l'avant-bras (Niunja So Sang Palmok Makgi).
17. Exécuter une frappe vers l'intérieur haute vers F avec le tranchant de la main gauche tout en ramenant le poing droit devant l'épaule gauche, maintenant la position en L gauche (Niunja So Sonkal Nopunde Anuro Taerigi).
18. Exécuter un coup de poing moyen vers F with le poing droit tout en glissant le pied droit vers F pour former une position fixe droite vers F (Gojung So Kaunde Yop Jirugi).
19. Ramener le pied droit vers le pied gauche, puis déplacer le pied gauche vers C pour former une position de marche gauche vers C tout en exécutant un blocage circulaire vers CF with l'avant-bras intérieur droit (Gunnun So An Palmok Dollimyo Makgi).
20. Exécuter un coup de pied frontal bas vers C avec le pied droit, en maintenant la position des mains du mouvement 19 (Najunde Apcha Busigi).
21. Poser le pied droit au sol vers C pour former une position de marche droite vers C tout en exécutant un coup de poing moyen vers C avec le poing gauche (Gunnun So Kaunde Bandae Jirugi).
22. Exécuter un blocage circulaire vers CE with l'avant-bras intérieur gauche tout en maintenant la position de marche droite vers C (Gunnun So An Palmok Dollimyo Makgi).
23. Exécuter un coup de pied frontal bas vers C avec le pied gauche, en maintenant la position des mains du mouvement 22 (Najunde Apcha Busigi).
24. Poser le pied gauche au sol vers C pour former une position de marche gauche vers C tout en exécutant un coup de poing moyen vers C avec le poing droit (Gunnun So Kaunde Bandae Jirugi).
25. Tourner le visage vers C en formant une position de préparation avec flexion gauche A vers C (Guburyo Junbi So A).
26. Exécuter un coup de pied de côté percutant moyen vers C avec le pied droit (Kaunde Yopcha Jirugi).
27. Poser le pied droit au sol sur la ligne CD, puis déplacer le pied gauche vers B en tournant dans le sens anti-horaire pour former une position en L droite vers B tout en exécutant un blocage de garde moyen vers B avec l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).
28. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers A pour former une position en L gauche vers A tout en exécutant un blocage de garde moyen vers A avec l'avant-bras (Niunja So Palmok Kaunde Daebi Makgi).

### FIN : Ramener le pied droit vers la posture de départ (Ready Posture).
