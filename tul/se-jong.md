# SE-JONG

> **Grade :** 5e Dan

* **Nombre de mouvements :**  24
* **Diagramme au sol :**  (Hanja pour le 'Roi')

| Diagramme | Description |
| ------ | ------ |
| ![**王**](../images/se-jong.png) | SE-JONG est nommé d'après le plus grand roi de l'histoire coréenne, Se-Jong le Grand, qui inventa l'alphabet coréen (Hangul) en 1443, et qui était également un météorologue réputé. Le diagramme (王) représente le Roi, tandis que les 24 mouvements correspondent aux 24 lettres de cet alphabet national. |

## Liste Détaillée des Mouvements

### Posture de départ : Position de préparation fermée B (Closed Ready Stance B / Moa Chunbi Sogi B).

1. Déplacer le pied gauche vers B pour former une position de marche gauche vers B tout en exécutant un blocage bas vers B avec l'avant-bras gauche (Gunnun So Palmok Najunde Makgi).
2. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers A pour former une position en L gauche vers A tout en exécutant un blocage double de l'avant-bras (Niunja So Sang Palmok Makgi).
3. Exécuter un coup de pied de côté percutant moyen vers D avec le pied droit (Kaunde Yopcha Jirugi).
4. Poser le pied droit au sol vers D, puis déplacer le pied gauche vers F pour former une position de marche gauche vers F tout en exécutant un blocage ascendant avec l'avant-bras gauche (Gunnun So Palmok Chookyo Makgi).
5. Ramener le pied gauche vers le pied droit, puis déplacer le pied droit vers E pour former une position assise vers D tout en exécutant une frappe moyenne vers E avec le tranchant de la main droite (Annun So Sonkal Kaunde Taerigi).
6. Ramener le pied droit vers le pied gauche pour former une position de préparation fermée B vers D (Moa Junbi So B).
7. Sauter vers D pour former une position en X gauche vers DG tout en exécutant une frappe de côté haute vers D avec le revers du poing gauche, ramenant le bout des doigts droits sur le poing gauche (Twigi, Wen Kyocha So Dung Joomuk Nopunde Yop Taerigi).
8. Déplacer le pied droit vers G pour former une position de marche droite vers G tout en exécutant un coup de poing haut vers G avec le poing droit (Gunnun So Nopunde Jirugi).
9. Déplacer le pied droit sur la ligne GH pour former une position fixe gauche vers H tout en exécutant un blocage de garde haut vers H avec l'avant-bras (Gojung So Palmok Nopunde Daebi Makgi).
10. Déplacer le pied droit vers H pour former une position de marche droite vers H tout en exécutant une poussée moyenne vers H avec le bout des doigts rectilignes (Straight Fingertip Thrust) droit (Gunnun So Sun Sonkut Kaunde Tulgi).
11. Ramener le pied droit vers le pied gauche, puis déplacer le pied gauche vers G pour former une position de marche gauche vers G tout en exécutant une frappe de côté haute vers G with le revers du poing gauche (Gunnun So Dung Joomuk Nopunde Yop Taerigi).
12. Déplacer le pied gauche sur la ligne GH pour former une position assise vers C tout en exécutant un blocage écopes avec la paume gauche (Annun So Sonbadak Duro Makgi).
13. Exécuter un coup de pied de côté percutant moyen vers C avec le pied gauche (Kaunde Yopcha Jirugi).
14. Poser le pied gauche au sol vers C dans un mouvement sauté pour former une position en X gauche vers CF tout en exécutant un blocage haut vers C avec le double avant-bras gauche (Twigi, Wen Kyocha So Doo Palmok Nopunde Makgi).
15. Déplacer le pied droit vers F pour former une position assise vers C tout en étendant le poing droit horizontalement vers C (exécuter en mouvement lent) (Annun So Soopyong Jirugi).
16. Exécuter une frappe frontale vers C avec le revers du poing gauche tout en maintenant la position assise vers C (Annun So Dung Joomuk Ap Taerigi).
17. Ramener le pied droit derrière le pied gauche, puis déplacer le pied gauche vers E pour former une position diagonale gauche vers C tout en exécutant un blocage pressant avec double paume (Sasun So Sang Sonbadak Noollo Makgi).
18. Exécuter un blocage moyen vers C avec double main en arc tout en formant une position de marche gauche vers CE (Gunnun So Doo Bandalson Kaunde Makgi).
19. Ramener le tranchant externe du pied gauche vers le genou droit pour former une position sur une jambe droite vers C tout en exécutant un blocage de côté haut vers F avec l'avant-bras extérieur droit et un blocage de côté bas vers E with l'avant-bras gauche (Waebal So Bakat Palmok Nopunde Yop Makgi, Palmok Najunde Yop Makgi).
20. Poser le pied gauche au sol vers D pour former une position de marche droite vers C tout en exécutant un blocage pressant with la paume droite (exécuter en mouvement lent) (Gunnun So Sonbadak Noollo Makgi).
21. Ramener le cou-de-pied gauche vers le creux de la jambe droite pour former une position sur une jambe droite vers C tout en frappant la paume gauche avec le revers de l'avant-bras droit (Waebal So Bakat Palmok Ap Taerigi).
22. Poser le pied gauche au sol vers C en tournant dans le sens horaire pour former une position fixe droite vers D tout en poussant vers C with le coude latéral gauche (Gojung So Yop Palkup Tulgi).
23. Déplacer le pied droit vers A pour former une position en L gauche vers A tout en exécutant un blocage de garde haut vers A avec le tranchant de la main (Niunja So Sonkal Nopunde Daebi Makgi).
24. Ramener le pied droit vers le pied gauche, puis déplacer le pied gauche vers B pour former une position en L droite vers B tout en exécutant un coup de poing moyen vers B avec le poing droit (Niunja So Kaunde Jirugi).

### FIN : Ramener le pied gauche vers la posture de départ (Ready Posture).
