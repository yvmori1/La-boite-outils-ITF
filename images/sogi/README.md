# Schémas des positions (*Sogi*)

Position des pieds au sol, vue de dessus, pour les 21 positions décrites dans
[../../Theorie/grammaire-itf.md](../../Theorie/grammaire-itf.md).

Ces images sont **générées**, jamais retouchées à la main :

```sh
python3 scripts/generer-sogi.py            # liste ce qui serait écrit
python3 scripts/generer-sogi.py --write    # écrit images/sogi/*.png
python3 scripts/generer-sogi.py --write --only gunnun-sogi
```

Chaque pied est posé par un point de repère nommé (talon, talon interne, gros
orteil, petit orteil, centre, bord interne) et non à l'œil : les mesures du
schéma sont donc celles de la position, et deux pieds « collés » se touchent
exactement, sans se chevaucher. Le dessin est construit sur les dimensions
standard — épaule 47 cm, pied 25 × 9 cm — mais **les cotes ne sont jamais
libellées en centimètres** : une longueur et une largeur se disent en largeurs
d'épaule, comme elles s'enseignent.

Conventions de lecture :

* chaque schéma est une vignette carrée de **350 × 350 pixels**, fond transparent ;
* le **haut** de l'image est la direction du déplacement ou du regard ;
* les positions dissymétriques sont dessinées **pied gauche avant** ;
* empreinte **pleine** = appui complet, **contour** = appui sur la plante
  seulement, **contour gris tireté** = pied en l'air ;
* les pourcentages indiquent la répartition du poids.
