# Chagi (차기) — Les coups de pied

Fiches détaillées des coups de pied du Taekwon-Do ITF. Chaque fiche décompose la technique : décomposition linguistique du nom coréen, surface de frappe (arme naturelle), armement, exécution étape par étape, erreurs fréquentes et applications.

Le nom des fichiers reprend la **romanisation coréenne** de la technique.

[← Retour à l'index général](../README.md)

## Fiches transversales

* [nomenclature.md](nomenclature.md) — vue d'ensemble de tout le vocabulaire des coups de pied, classé par famille d'action (*Busigi*, *Jirugi*, *Dollyo*, *Twimyo*…). **Point d'entrée recommandé.**
* [Dans-les-formes.md](Dans-les-formes.md) — dans quelles formes (Tul) chaque coup de pied apparaît.
