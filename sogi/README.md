# Sogi (서기) — Les positions

Une fiche par position d'appui et par position de préparation : placement des pieds, répartition du poids, erreurs fréquentes. Les positions sont la base de toutes les techniques complètes de [Techniques](../Techniques/README.md), dont le nom commence par celui de la position (*Gunnun So*, *Niunja So*…).
