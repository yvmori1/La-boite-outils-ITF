# Jirugi (지르기) — Les frappes de la main

Fiches détaillées des attaques portées avec le haut du corps : poings, mains ouvertes, piques de doigts et coudes. Chaque fiche décompose la technique : sens du nom coréen, arme naturelle employée, armement, trajectoire, force de réaction et cibles.

Trois natures d'action se distinguent dans les noms :

* **Jirugi (지르기)** — poussée perçante et rectiligne, effet piston, hanches profondément engagées.
* **Taerigi (때리기)** — frappe cinglante ou fouettée, obtenue par la vitesse d'extrémité.
* **Tulgi (툴기)** — pique pénétrante dans une ouverture étroite.
