# Combats arrangés — 3e Gup (ceinture bleue barre rouge)

Fiche du grade : [Bleu I](../../9-progression/ceintures/08_Bleu_I.md) · Forme du niveau : [*Toi-Gye*](../../6-formes/fiches/toi-gye.md)

Par convention, la première attaque se fait du côté droit ; chaque combat se travaille ensuite autant à droite qu'à gauche.

## Combat arrangé #12 — 1 pas de *Toi-Gye*

| Étape | Technique |
| :--- | :--- |
| Attaque | [Coup de poing direct au niveau haut en position de marche](../../5-repertoire-technique/combinees/Gunnun-So-Nopunde-Jirugi.md) |
| Défense | Reculer avec un [blocage en W en position assise](../../5-repertoire-technique/combinees/Annun-So-Bakat-Palmok-San-Makgi.md) |
| Contre-attaque | Déplacer la jambe avant à l'intérieur de l'attaquant avec un pic de main angulaire haut en position de marche |
